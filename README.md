# GTA VI Trophy Rarity Forecast

Forecasts each GTA VI PlayStation 5 trophy's Exophase earn rate at the target time, blending logit-scale trend models against time and tracked-player growth with an earners-count model, using tier-pooled shrinkage across trophies. It emits five quantiles per trophy whose spread reflects residual volatility, model disagreement, and the forecast horizon.
